ArcGIS Pro Training

Master professional GIS mapping, spatial analysis and cartography.

ArcGIS Pro is professional GIS software used by governments, universities and companies for mapping and spatial analysis.

Example
The Nigerian Ministry of Works can use ArcGIS Pro to map federal roads and identify damaged sections.
Practice
Open ArcGIS Pro and create a new project called My First GP3D Project.

Every ArcGIS Pro project stores your maps, data and layouts in one organised place.

Example
Instead of saving roads, rivers and schools separately, keep them inside one project.
Practice
Save your project inside a folder named GP3D Training.

Coordinate systems tell the computer the exact location of every feature on Earth.

Example
If Lagos is placed in the wrong coordinate system, it could appear hundreds of kilometres away.
Practice
Set your map coordinate system to WGS 1984.

Digitizing means drawing real-world features from satellite imagery.

Example
Trace a road, draw a school building and outline a football field.
Practice
Draw one road and one building from satellite imagery.

Georeferencing aligns old maps or scanned documents with their real-world locations.

Example
A scanned map of Ilorin from 1985 can be aligned with today's satellite image.
Practice
Move a scanned image until its roads match satellite imagery.

Spatial Join combines information from two map layers based on location.

Example
Automatically determine which Local Government each school belongs to.
Practice
Join schools with Local Government boundaries.

A buffer creates a specified distance around a feature.

Example
Create a 500-metre emergency zone around a hospital.
Practice
Buffer one road by 100 metres.

Overlay combines multiple layers to solve planning problems.

Example
Find the best place for a new hospital by combining roads, population and available land.
Practice
Overlay roads and rivers to identify possible bridge locations.

Raster analysis works with satellite images and Digital Elevation Models (DEMs).

Example
A slope map helps engineers avoid building on steep hills.
Practice
Use a DEM to calculate slope.

A good map includes a title, legend, scale bar and north arrow.

Example
Prepare an A4 map suitable for a university dissertation.
Final Project
Create a professional map of Ilorin and export it as a PDF.
